A green-bar reversal bot for cbBTC/USDC on 1-minute bars: it waits for a deep washout — the close at least 1% below the 120-bar high — and only buys when the bar that just closed is green, the first sign sellers are exhausted. It exits on take-profit, stop-loss, trailing stop or a 6-hour time stop. Long only, fully deterministic, standard library only.

## Run it

```sh
node main.ts
```
